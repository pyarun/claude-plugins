# claude-plugins

Claude Code plugins by [Arun Mittal](https://github.com/pyarun).

```
/plugin marketplace add pyarun/claude-plugins
/plugin install pyarun@pyarun-plugins
```

| Plugin | What it does |
|---|---|
| [pyarun](plugins/pyarun) | Arun's toolkit, commands under `/pyarun:`. Includes the work observer: mines your Claude Code sessions every day for posts, articles, talks, learning gaps and habits, and files them in an idea library. macOS. |
